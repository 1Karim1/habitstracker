📱 Samsung Galaxy A55 5G Installation & Android APK Guide

1. Instant Offline PWA Installation on Galaxy A55 (Chrome / Samsung Internet):

Open this application in Chrome or Samsung Internet on your Galaxy A55, tap the browser menu (⋮ or ≡), and select "Add to Home screen" / "Install app". The app caches all assets offline via Service Worker and persists all data in IndexedDB.

2. Native Standalone Android APK Build (Capacitor Project Bundle Included):

Unzip the companion habit_tracker_galaxy_a55_android_pwa_project.zip archive and run:

npm install
npx cap add android
npx cap sync android
cd android && ./gradlew assembleDebug

Then install android/app/build/outputs/apk/debug/app-debug.apk onto your Samsung Galaxy A55 via adb install -r app-debug.apk (using -r preserves your existing IndexedDB database across APK updates).
